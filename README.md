# Password Saver v0.0.1

**Password Saver** is a simple beginner-friendly password management project written in Python, featuring a retro command-line interface inspired by MS-DOS programs from the 1980s.

The program allows users to save website credentials, including website names, usernames, and passwords, into local text files and retrieve them whenever needed.

### ✨ Features
- Add and save website credentials.
- View previously saved credentials.
- Store data in local `.txt` files.
- Simple, menu-based command-line interface.
- Retro MS-DOS-inspired design and experience.

### 🎯 Purpose
This project is a great practice exercise for beginners who want to improve their Python programming skills. It provides hands-on experience with user input, functions, loops, conditional statements, and file handling.

### 🖥️ Design
The interface is inspired by classic MS-DOS applications from the 1980s, bringing a touch of old-school computing nostalgia to a simple Python project.

### ⚠️ Disclaimer
This is an early learning project and is **not intended for storing real or sensitive passwords**. Passwords are saved as plain text without encryption.

### 🛠️ Technologies
- Python 3
- File Handling
- Command-Line Interface (CLI)
